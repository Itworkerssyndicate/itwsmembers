## 📖 نظرة عامة

**نقابة تكنولوجيا المعلومات والبرمجيات** هي منصة رقمية متكاملة تهدف إلى:

- تسهيل عملية تقديم طلبات العضوية إلكترونيًا
- أتمتة الفحص الأولي للمستندات (AI)
- إتاحة متابعة الطلبات لحظيًا للأعضاء
- توفير لوحات تحكم كاملة للنقيب واللجنة
- إدارة الاشتراكات والإيرادات والأعضاء

---

## ✨ المميزات

### 🎬 الواجهة العامة

- **شاشة افتتاحية** سينمائية (5 ثواني) مع خلفية تكنولوجية
- **صفحة رئيسية** بمميزات ديناميكية من الإعدادات
- **7 ثيمات** قابلة للتخصيص لكل مستخدم
- **تحديث فوري** بدون إعادة تحميل (Realtime)
- **متجاوبة** على كل الأجهزة

### 📝 تقديم العضوية

- **فورم ذكي** متعدد الأقسام
- **رفع مرفقات** (بطاقة، شهادة، صورة، شهادة عمل، فيش وتشبيه)
- **تصوير مباشر** من الكاميرا (موبايل + كمبيوتر)
- **فحص تلقائي** للمستندات بـ **Tesseract.js** (OCR)
- **منع التكرار** بنفس الرقم القومي
- **إيصال فوري** مع QR Code
- **حفظ تلقائي** للمسودة

### 🔍 تتبع الطلب

- بحث برقم التتبع أو الرقم القومي
- **Timeline كامل** لمراحل الطلب
- **تحديث لحظي** للحالة
- **رفع المستندات الناقصة** مباشرة
- QR Code لكل طلب

### 👥 لوحة لجنة العضوية

- عرض كل الطلبات مع فلاتر متقدمة
- **8 كروت إحصائية** قابلة للنقر
- **تقرير المحافظات** التفاعلي
- تحديث حالة الطلبات
- **تحديد الأوراق الناقصة** بسهولة
- تصدير CSV

### 👑 لوحة النقيب العام

- **إدارة كاملة** للإعدادات
- **محرر المميزات** (إضافة/تعديل/حذف كروت)
- **إدارة المستخدمين** (3 أدوار)
- **إدارة الشعب** و أنواع العضوية
- **سجل النشاط** و **سجل التدقيق**
- **اعتماد أرقام العضوية**
- **إدارة الإيرادات** و **الاشتراكات**

### 👤 إدارة الأعضاء

- **قاعدة بيانات كاملة** للأعضاء المقبولين
- **تتبع الاشتراكات** والانتهاءات
- **تجديد فردي** و **جماعي**
- **تقارير مالية** بين تاريخين
- **بحث متقدم** (اسم، رقم عضوية، رقم قومي، شعبة، محافظة)
- **تصدير Excel/PDF**

### 🛡️ الأمان

- **Row Level Security** على كل الجداول
- **منع F12** و DevTools
- **منع الكليك يمين** و النسخ
- **كشف العبث** وتسجيله
- **3 أدوار** بصلاحيات دقيقة

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **HTML5** | هيكل الصفحات |
| **CSS3** | التصميم + 7 ثيمات |
| **JavaScript (Vanilla)** | المنطق والتفاعل |
| **Canvas API** | الرسوم المتحركة |
| **Supabase** | Database + Auth + Storage + Realtime |
| **PostgreSQL** | قاعدة البيانات |
| **Tesseract.js** | OCR للفحص التلقائي |
| **html2canvas** | تحويل الإيصالات لصور |
| **GitHub Pages** | الاستضافة |
| **QR Server API** | توليد رموز QR |
