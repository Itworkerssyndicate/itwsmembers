إعادة بناء قاعدة البيانات

سيتم مسح كل الجداول والبيانات القديمة، وإنشاء قاعدة بيانات جديدة بالكامل.
حساب النقيب (Auth) لن يمس

تحذيرات مهمة

  • هيتم مسح كل الطلبات القديمة نهائيًا
  • هيتم مسح كل المرفقات والملفات من الـ Storage
  • هيتم مسح كل الإعدادات القديمة
  • هيتم مسح كل المستخدمين من جدول users (لكن حسابك في Auth سليم)
  • لن تستطيع استرجاع أي شيء بعد التنفيذ
  • بعد التنفيذ، لازم تختار نفسك (النقيب) تاني من جدول users
1
نسخ سكربت المسح
افتح SQL Editor في Supabase، الصق السكربت، ونفّذه. ده هيمسح كل الجداول والـ Buckets القديمة.
🔗 افتح SQL Editor
2
نسخ سكربت البناء الجديد
في نفس الصفحة (SQL Editor)، الصق السكربت الجديد ونفّذه. ده هيعمل كل الجداول الجديدة.
3
تأكيد حساب النقيب
حسابك في Auth (بريد + كلمة مرور) لسه موجود. لكن لازم نضيفه في جدول users تاني.
افتح Authentication → Users، انسخ الـ UID بتاع حسابك.
الخطوة الجاية:
1. روح على Authentication → Users
2. اضغط على حسابك
3. انسخ الـ User UID
4. ارجع هنا والصقه في الخانة اللي تحت
هتلاقيه في صفحة Authentication → Users
head = النقيب العام | vice_president = نائب الرئيس | committee = لجنة العضوية
🔗 افتح Users
4
التحقق من كل شيء
بعد تنفيذ كل الخطوات، دوس على الزرار ده للتأكد إن كل حاجة موجودة.
5
ملخص الإعداد

تم الإعداد بنجاح

🚀 افتح صفحة الدخول
