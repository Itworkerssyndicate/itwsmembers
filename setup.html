Setup — الإعداد الكامل

اتبع الخطوات بالترتيب — كل خطوة لازم تخلص قبل اللي بعدها

⚠️ تحذير: الخطوة 1 ستمسح كل الجداول والبيانات القديمة. حساب النقيب في Auth لن يتأثر.
1
مسح قاعدة البيانات القديمة
جاهز
افتح SQL Editor، والصق السكربت، ونفّذه. ده هيمسح كل الجداول والدوال والـ Policies القديمة.
2
إنشاء الجداول
جاهز
14 جدول كامل مع كل الأعمدة والعلاقات.
3
إنشاء الدوال
جاهز
7 دوال SQL (منها الترقيم التسلسلي + إصلاح الكومنتات).
⚠️ لازم تخلص الخطوة دي قبل الـ Policies
4
الفهارس والـ Triggers
جاهز
24 Index للأداء + 5 Triggers تلقائية (تسجيل تغيير الحالة، الترقيم التسلسلي).
5
البيانات الافتراضية
جاهز
4 أنواع عضوية + 6 شعب + 30+ إعداد افتراضي.
6
الأمان (RLS + Policies)
جاهز
45+ Policy لتنظيم الوصول لكل جدول حسب دور المستخدم.
7
تأكيد حساب النقيب
جاهز
حسابك في Auth موجود بالفعل. لازم نضيفه في جدول users تاني بدور head.
الخطوات:
1. افتح Authentication → Users
2. اضغط على حسابك
3. انسخ الـ User UID
4. املأ البيانات تحت

🎉 تم الإعداد بنجاح!
