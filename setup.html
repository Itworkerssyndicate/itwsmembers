Setup — إعداد المنصة

اتبع الخطوات بالترتيب — كل خطوة هتتعلّم عليها ✓ لما تخلص

1
تحضير دالة SQL المؤقتة
افتح SQL Editor في Supabase، والصق الكود ده، ودوس Run.
CREATE OR REPLACE FUNCTION exec_sql(sql text) RETURNS void LANGUAGE plpgsql SECURITY DEFINER AS $$ BEGIN EXECUTE sql; END; $$; GRANT EXECUTE ON FUNCTION exec_sql(text) TO service_role; GRANT EXECUTE ON FUNCTION exec_sql(text) TO authenticated;
🔗 افتح SQL Editor
2
تنفيذ الإعداد الكامل
في نفس الصفحة (SQL Editor)، الصق الكود ده كله، ودوس Run. هيعمل كل الجداول والإعدادات والصلاحيات.
3
إنشاء حساب النقيب العام
اذهب إلى Authentication → Users، ودوس Add user → Create new user. املأ البيانات واضغط Create user، وبعدها انسخ الـ UID بتاعه.
البيانات المقترحة:
📧 الإيميل: head@itsyndicate.eg
🔒 الباسورد: اختر كلمة قوية (احفظها!)
✅ Auto Confirm User: فعّلها
🔗 افتح Users
4
تعيين النقيب كـ Head
اذهب إلى Table Editor → users → Insert row، واملأ الحقول بالبيانات اللي تحت.
البيانات المطلوبة:
